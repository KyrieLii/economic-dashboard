# Economic Dashboard · 经济数据看板

[English](README.md) | **简体中文**

在一个页面查看 A 股、美股、港股、大宗商品、汇率、利率和加密货币行情，保存历史数据，追踪趋势并查阅数据来源与修订记录。

## 功能

- 内置 34 项指标，包含 5 项市场成交额指标及 BTC、ETH，按六组卡片展示。支持搜索、关注，以及红涨绿跌 / 绿涨红跌切换。
- 点击卡片打开详情侧栏，查看历史曲线、区间变化、最高值和最低值；支持鼠标与键盘查看各日期的数据。
- 支持最近 1 个月、3 个月、1 年、全部历史和自选日期范围，可导出 CSV。
- 按日采集数据，首次补齐可获取的历史，之后增量更新。采集失败时保留已有数据，并显示数据日期、错误信息与历史覆盖范围。
- 按指标和日期去重，保留价格、成交量及来源的修订记录，防止多个采集任务同时执行。
- 支持 Docker 定时采集、Vercel Cron、数据库备份，以及将备份恢复到空数据库。

### 自定义布局

在“设置 → 编辑布局”中添加、移除或排序卡片。拖动整张卡片时，其他卡片会自动让位；拖动组标题可调整分组顺序，拖到另一组底部可另起一行。也可使用箭头和换行按钮调整布局，按 Esc 撤销当前拖动。

卡片采用固定宽度并左对齐，可在设置中调整为 160–300 px。编辑时点击“保存”应用布局和宽度，也可取消修改或恢复默认；非编辑状态下调整宽度会立即保存。卡片的数据日期放在信息提示中，页面右下角显示最近采集时间。

### 搜索与追踪资产

在“设置 → 新增”中搜索内置指标，或按市场搜索 A 股（沪深北）、港股、美股和加密货币。例如：

- `600519` / 茅台
- `00700` / 腾讯
- `AAPL` / 苹果（输入 `APEL` 时会自动纠正为 `AAPL`）
- `SOL` / Solana，或 `DOGE` / 狗狗币

首次添加资产时会补齐可获取的历史数据，之后随定时任务更新，最多支持 50 项自定义资产。股票按交易所当地日期记录；加密货币仅保存已结束的 UTC 日线，不提供实时盘中报价。

设置右侧的语言按钮可切换中文和英文。语言、布局与卡片宽度保存在当前浏览器中，不跨设备同步；资产信息和历史数据保存在 SQLite / Turso。移除卡片只会将其隐藏，不会删除历史或停止采集。

## 本地启动

需要 Node.js 24 LTS 和 pnpm 11。

```sh
pnpm install
cp .env.example .env
pnpm collect
pnpm dev
```

前端默认地址为 `http://127.0.0.1:5173`，端口被占用时会自动切换；API 默认使用 3001 端口。数据库为空时，页面显示暂无数据，不生成模拟行情。

```sh
pnpm collect us10y sofr              # 采集指定指标
pnpm collect csi300 --backfill       # 补齐历史并复核修订
pnpm test
pnpm build
pnpm start                          # 生产模式，默认使用 3001 端口
pnpm backup
pnpm restore backups/<文件>.json     # 仅支持恢复到空数据库
```

本地数据库默认位于 `file:data/economic.db`。如需通过代理采集数据，在 `.env` 中设置 `DATA_PROXY_URL`。任一指标采集失败时，命令会以非零状态退出，已成功采集的数据仍会保存。

## 部署

点击上方 **Deploy with Vercel** 按钮，即可复制仓库并创建自己的部署。请先创建 Turso 数据库；部署页面会要求填写 `TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN` 和 `CRON_SECRET`（可用 `openssl rand -hex 32` 生成）。部署完成后，按[部署文档](docs/deployment.md#vercel--turso)执行首次采集。

- **Vercel**：静态前端 + Node Function + Turso。需配置 `TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN` 和 `CRON_SECRET`，不能依赖函数的本地文件持久保存历史数据。

配置方法及部署验证范围见[部署文档](docs/deployment.md)。

## 数据范围与限制

内置指标定义见 [shared/catalog.ts](shared/catalog.ts)，各来源的接入情况见[数据说明](docs/data-plan.md)。

2026-11-27 的本地验证结果：34 项内置指标均有数据，共 29,721 条记录。上证 50、中证 1000 各有 727 条，BTC、ETH 各有 1,826 条；5 项市场成交额指标各覆盖 33 个交易日，自 2026-10-14 起。其他指标约有 2–5 年历史，实际覆盖范围以页面显示为准。这是当次验证结果，不代表新部署自带这些数据；新部署需要首次采集或从备份恢复。

- 卡片可显示来源提供的当前报价，可能延迟；迷你图、详情曲线和CSV仍使用已完成日线。盘中报价不覆盖历史收盘价，不保存分时历史，也不为休市日期补造数据。
- 加密货币当前报价的涨跌幅相对来源前收价，历史日线涨跌按相邻的已结束 UTC 日线计算；两者均不代表滚动 24 小时涨跌幅。
- 公开行情接口不保证持续可用，接口变更后可能需要更新采集逻辑。
- A 股市场成交额与指数行情分开统计，包含沪深北合计、沪深合计和三家交易所分项。数据来自交易所官方日度统计，不含 B 股、基金、债券和回购。
- **完整 A 股成交量（股数）尚未提供。** 已取得上交所、北交所的成交股数，但深市仅含 A 股的成交股数仍待核实。不会用含 B 股的合计或指数成交量代替。
- 大宗商品使用近月期货价格，换月可能造成价格跳变；图表中的区间变化不代表实际投资收益。
- 利率变化以基点表示；EFFR 为有效联邦基金利率，不是政策目标区间。
- 尚未接入 LPR、政策目标区间、完整 A 股成交股数、ETF 总回报及宏观日历。
- 距今超过 4 天的记录标为“较早数据”。该标记仅提示数据距今的天数，未完整考虑各交易所的休市日历。

## 项目结构

- `src/`：React 单页界面、SVG 图表与数据查询。
- `shared/`：指标定义、类型与格式化工具。
- `server/`：API、数据源、存储、采集与调度。
- `api/`：Vercel Node Function 入口。
- `scripts/`：采集、备份与恢复脚本。
- `tests/`：数据一致性、解析、调度与鉴权测试。

`.env`、数据库、备份和日志均不提交到 Git。密钥仅在服务端使用，不要为含密钥的环境变量添加 `VITE_` 前缀。

`DASHBOARD_PASSWORD` 用于保护行情读取、搜索和新增资产接口，HTTP Basic 用户名为 `viewer`；静态页面和 JavaScript 资源仍可公开访问。未设置密码时，任何访问者都能读取行情、搜索和添加资产，并使用共享的采集与存储资源。公网部署应设置强密码并启用 HTTPS；定时采集接口由独立的 `CRON_SECRET` 保护。当前为共享实例，尚无用户隔离或请求限流。

## 盘中报价

打开看板后，当前布局中的行情卡片及打开的详情每60秒检查一次报价；上证50、中证500等指数可在交易时段显示来源提供的当前点位和相对昨收涨跌幅。刷新按钮同时检查报价和读取已存数据。切到后台停止定时轮询，回到页面检查过期报价。关闭页面后不持续拉取盘中报价，每日历史采集继续按计划运行。

卡片 tooltip 显示来源实际报价时刻，不能把抓取成功时间当作行情时刻。免费来源可能延迟，刷新频率不代表交易所级实时性。利率、美债收益率和全市场成交额仍按原来源的日频发布数据更新。

SQLite / Turso 共享缓存将同一资产的来源请求间隔限制为至少60秒，手动刷新和多个访问者共用缓存。失败保留上次报价并提示；没有可用报价时回退到历史日线。迷你图、详情曲线、CSV和历史修订仍使用已完成日线，盘中报价不覆盖收盘记录。`quote_cache` 只保存最新报价，不保存分时历史，也不进入历史备份。此功能使用普通函数和数据库额度，不增加高频定时任务。
